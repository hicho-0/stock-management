# Gestion Stock Pro

Gestion de stock, caisse, clients (crédit et paiements), dépenses et rapports pour un petit magasin. Hors ligne, en français, montants en DA.

Fichiers : `app.html` (l’application), `main.js` + `preload.js` (fenêtre Windows), `index.html` + `capture-*.png` (page de téléchargement), `.github/workflows/build.yml` (fabrication de l’installateur).

Données sur le PC : `Documents\Gestion Stock Pro\donnees.json` + `sauvegardes\` (copie quotidienne, 30 jours).
